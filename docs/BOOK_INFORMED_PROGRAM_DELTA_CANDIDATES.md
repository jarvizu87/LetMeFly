# LetMeFly Book-Informed Program Delta Governance

Status: **Black Crown Revised v2.1 and Crownforge v2.2 are the approved book-informed program revisions.**

## Purpose

The private Training Intelligence book/manual library can validate existing LetMeFly rules or create intentional revision candidates. It cannot silently rewrite a runnable program. The governing principles remain **REPLACE > ADD**, program-specific authority, explicit revision/version control, and full regression before promotion.

## Crownforge v2.2 — approved final book-informed refinement

The final Crownforge-only book audit compared the expanded book/manual findings against the actual Crownforge v2.1 prescriptions rather than importing outside methods wholesale.

### KEEP

The audit keeps Crownforge's main architecture unchanged:

- 14-week Crownforge structure / 98 calendar days;
- separate 3-week Crown Maintenance bridge;
- primary strength prescriptions and progression;
- Olympic derivatives as technically governed, low-fatigue power work;
- Day 5 KB / sled / GPP identity and anti-make-up governance;
- main kettlebell progression;
- Week 12 true deload;
- Weeks 13–14 governed testing / handoff.

### MODIFY — exact v2.2 prescription change

Across **Weeks 1–12, Day 6**, the existing light KB Swing primer changes from `mandatory` to `conditional`.

- keep the existing load and exact **2 x 10** dose when used;
- use it only when hinge timing/stiffness needs a technical ramp;
- omit it when Day-5 GPP was fully completed and the Day-6 hinge pattern is already crisp;
- never use it as make-up GPP;
- keep the actual Day-6 KB Swing working dose unchanged.

This is a fatigue/duplication refinement, not a reduction in Crownforge's actual kettlebell-development work.

### REJECT

The final audit rejects these additions because their complexity or recovery cost is not justified for Crownforge's rebuilding purpose:

- more Olympic-lifting volume;
- more kettlebell volume;
- more sled/GPP volume;
- full Triphasic eccentric/isometric/concentric blocks;
- APRE replacing source-owned loading;
- exercise rotation for novelty;
- advanced-method complexity without a diagnosed need.

## Black Crown Revised v2.1 — approved Block-5 lateral-glute amendment

The earlier book review identified hip abduction as a distinct lateral-glute role that was not directly represented in Black Crown Block 5. The v2.0 source had deliberately decided against an additional loaded glute slot. The athlete subsequently made an explicit program-edit decision to improve that specialization architecture.

The resulting v2.1 change is deliberately **replacement-only**, not additive.

### Exact prescription change

Only **Weeks 25–29, Day 5** change:

- retain primary Chest-Supported Row 4 x 8–10;
- retain Lat Pulldown 2–3 x 8–10;
- replace the later secondary Chest-Supported Row 2 x 8–10 support slot with **Machine Hip Abduction 2 x 15–25 @ RPE 7–8**;
- rest **45–60 seconds**;
- equipment fallback order: **Seated Band Hip Abduction**, then **Mini-Band Lateral Walk**;
- no new session, no extra support slot, and no added total support-set count.

Week 30 remains the existing non-max check and is unchanged.

## Other book-informed conclusions

- Black Crown B5 chest volume stays unchanged.
- Full Triphasic blocks remain future weakness-specific tools rather than default program content.
- APRE stays advisory/research around authorized checks and does not replace percentage/TM authority.
- Velocity-based evidence supports a future private **crisp / slowing / grind** quality observation in Coach Mode rather than automatic load rewriting.
- Workload/overlap analytics remain the preferred evidence layer before any further volume changes.

Black Crown v2.1 retains its independent 54/270/42 production invariants and remains protected by its own source/runtime audits.
