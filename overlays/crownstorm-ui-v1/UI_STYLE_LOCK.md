# Crownstorm UI Style Lock

## Primary reference

The favorite **Quests** screen is the interaction and density reference for the subsystem.

Characteristics:

- near-black background
- violet/purple edge lighting and controls
- thin runic/storm borders
- dense but readable cards
- serif/display headings + clean functional body copy
- featured mission art card at top
- tabs: Daily / Weekly / Habits / Challenges
- clear checkboxes/progress and XP on the right

## Rank & Rewards lock

Rank & Rewards uses the **Raizen seated on the Stormvault throne** artwork as the hero image.

## Home exclusion

The Command V2 Home dashboard is not part of Crownstorm's styling surface and is not altered by this subsystem.
