# Stormvault Cache Rules

## Core rule

Stormvault Caches are **earned, never purchased**.

No real-money randomized boxes are part of the design.

## Tiers

- Iron Cache — common quest/achievement reward
- Storm Cache — complete structured week / meaningful streak
- Fenrir Cache — program node / major achievement / 30-day streak
- Black Crown Cache — rank promotion or special governed milestone
- Sovereign Vault — program completion / endgame milestone

## Contents

- Crown Shards
- profile frames
- titles
- badges
- Raizen form/profile art
- banners
- aura effects
- Fenrir/Crownstorm emblems

No cache may contain:

- XP multipliers
- workout-load boosts
- automatic PRs
- training-max changes
- program skips
- readiness overrides
- extra programmed work
- recovery waivers

## Duplicate protection

Duplicate cosmetics are never retained as junk. They automatically convert to their configured Crown Shard value.

## Determinism / auditability

A cache's rewards are seeded from its immutable earned-cache ID and earned timestamp. Reopening or replaying the same cache returns the same result and cannot pay twice.
