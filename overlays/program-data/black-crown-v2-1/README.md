# Black Crown Revised v2.1 — Lateral-Glute Specialization Amendment

This overlay is an **intentional program revision** authorized after the book-informed Training Intelligence review.

It layers on top of the immutable, hash-audited Black Crown Revised v2.0 source package. The v2.0 transport remains unchanged and continues to provide the canonical 54-week / 270-session base.

## v2.1 prescription change

Only Block 5, Weeks 25–29, Day 5 changes:

- retain the primary Chest-Supported Row 4x8–10;
- retain Lat Pulldown 2–3x8–10;
- replace the later redundant Chest-Supported Row 2x8–10 support slot with **Machine Hip Abduction 2x15–25 @ RPE 7–8**;
- use **45–60 sec rest** for the hip-abduction work;
- use Seated Band Hip Abduction, then Mini-Band Lateral Walk, as role-preserving equipment fallbacks;
- the replacement is set-neutral: no new session, no new section, and no added support slot.

Week 30 remains the existing non-max check and is not changed.

## Governance

This amendment intentionally supersedes the v2.0 source-local statement that no additional loaded glute slot should be used. It does so by **replacement, not addition**, after explicit athlete approval and book-informed review.

Crownforge and Crown Maintenance are protected by tree hashes and may not change when this overlay is applied. Black Crown's 54 weeks, 270 sessions, test/check schedule, Strict OHP schedule, TM/loading rules, Day-4 recovery identity, and all other prescriptions remain unchanged.
