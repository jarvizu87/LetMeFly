# Crownforge v2.2 — Book-Informed Final Audit Amendment

Status: **approved targeted refinement**.

Crownforge v2.2 is intentionally small. The expanded Training Intelligence book/manual review did **not** justify changing Crownforge's primary lifts, weekly architecture, Olympic-derivative volume, sled/GPP structure, main kettlebell progression, deload/test/handoff structure, or Weeks 13–14 testing.

## KEEP

- 14-week Crownforge structure / 98 calendar days.
- Separate 3-week Crown Maintenance bridge.
- Primary strength prescriptions and progression.
- Olympic derivatives as low-fatigue, technically governed power work.
- Day 5 KB / sled / GPP identity and FLEX / anti-make-up governance.
- Day 6 full-body work and its actual main KB Swing dose.
- Week 12 true deload.
- Weeks 13–14 governed testing / handoff.

## MODIFY — the only prescription change

Across **Weeks 1–12, Day 6**, the existing light KB Swing primer remains exactly **2 x 10 at the existing week-specific primer load** when used, but its priority changes from `mandatory` to `conditional`.

Use it when hinge timing or stiffness needs a technical ramp.

Omit it when:

1. Day 5 KB/sled/GPP was fully completed, and
2. the Day 6 hinge pattern is already crisp.

It may never be used as make-up GPP. The main Day 6 KB Swing dose remains unchanged.

## REJECT

The final book-informed audit rejected the following as unnecessary or overly costly for Crownforge's rebuilding purpose:

- adding Olympic-lifting volume;
- adding kettlebell volume;
- adding sled/GPP volume;
- full Triphasic eccentric/isometric/concentric blocks;
- APRE replacing source-owned loading;
- exercise rotation for novelty;
- advanced-method complexity without a diagnosed need.

## Governance

This is a versioned v2.1 → v2.2 amendment, not a rewrite. Black Crown Revised v2.1 and Crown Maintenance must remain byte-for-byte protected while the amendment applies. All Crownforge prescriptions outside the Day-6 primer priority/note are protected by exact file-scope and regression audits.
