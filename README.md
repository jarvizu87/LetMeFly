# LetMeFly

LetMeFly is a strength, conditioning, and coaching application built around a **public app shell + private athlete data** architecture.

This repository contains only public application/program logic. Personal athlete profiles, training maxes, workout history, readiness data, notes, and other private athlete state must not be committed here.

## Monday release target

The current release candidate is prepared for Crownforge Week 1 Day 1 on September 7, 2026, with local-first workout logging and offline/PWA support.
